# 심연 원정 (Abyss Expedition)

오리지널 2D 탑다운 던전 액션. `index.html`을 브라우저로 열면 바로 실행됩니다 (진행은 자동 저장).

## 조작
- WASD 이동 · 마우스 조준 · 좌클릭 도끼 공격 (3타째 회전베기)
- Space / 우클릭 / Shift 구르기(무적) · Q 광폭화(분노 100)
- 1~4 영혼 스킬 · F 물약 · E 문/상자 · P 일시정지 · M 소리

## 구조
- `data.js` — 이름, 설명, 수치, 테마, 이미지 경로 (여기만 고치면 텍스트·밸런스 변경)
- `game.js` — 게임 로직과 렌더링
- `assets/` — 교체용 이미지 (방법은 assets/README.md)
